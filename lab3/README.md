# Лабораторная работа №3. Дикторские модели

Основной файл работы: `lab3_blank.ipynb`.

В ноутбуке реализованы:

1. подготовка списков VoxCeleb1;
2. ResNet-кодировщик со статистическим пулингом;
3. обучение с AAM-Softmax;
4. онлайн-аугментация шумом и реверберацией;
5. загрузка готовых моделей и сравнение accuracy;
6. ответы на контрольные вопросы.

Готовые модели должны находиться по путям:

```text
../data/lab3_models/lab3_model_0039.pth
../data/lab3_models_aug/lab3_model_0039.pth
```

Обучение по умолчанию выключено переменной `RUN_TRAINING = False`. Для проверки
готовых моделей достаточно последовательно выполнить ячейки ноутбука. Повторное
обучение занимает много времени и для сдачи работы не требуется.

Сохранённые результаты:

| Модель | Accuracy |
|---|---:|
| Без аугментации | 92.732% |
| С аугментацией | 92.099% |

Модель без аугментации была получена ранней версией кода, которая использовала
1211-мерный выход ResNet непосредственно как логиты классов. Для неё оставлена
отдельная совместимая функция `test_legacy_classifier`. Новое обучение выполняется
через корректную связку ResNet -> эмбеддинг -> AAM-Softmax.
