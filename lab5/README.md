# Лабораторная работа №5. Адаптация и калибровка

Основной файл работы: `lab5_blank.ipynb`.

Реализованы:

1. извлечение дикторских эмбеддингов для исходных и искажённых записей;
2. вычисление косинусных оценок;
3. симметричная s-нормализация по импосторной когорте;
4. воспроизводимая генерация калибровочного протокола;
5. линейная калибровка оценок логистической регрессией;
6. расчёт EER, minDCF и actDCF;
7. ответы на контрольные вопросы.

Сохранённые результаты:

| Этап | EER | minDCF | actDCF |
|---|---:|---:|---:|
| Исходная in-domain система | 3.723% | – | – |
| После s-нормализации | 2.929% | – | – |
| До калибровки | 1.308% | 0.0258 | 0.9115 |
| После калибровки | 1.308% | 0.0258 | 0.0297 |

Для полного повторного запуска требуются VoxCeleb1 dev/test и файл весов
`data/models/baseline_v2_ap.model`. Если файла весов нет, ноутбук загрузит его по
ссылке из `data/lists/models.txt`.
